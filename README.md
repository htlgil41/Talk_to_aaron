# Talk To Aaron

**Talk To Aaron** es una aplicación móvil desarrollada con **Flutter** que simula una interacción de chat con un contacto llamado **"Aaron Gil"**. Este proyecto fue creado como un ejercicio práctico para consolidar conocimientos fundamentales sobre el desarrollo de interfaces y lógica de flujo en Flutter.

---

## Funcionalidades

* **Interfaz de Chat Intuitiva:** Diseño limpio inspirado en aplicaciones de mensajería modernas.
* **Lógica de Respuesta:** La aplicación analiza el mensaje del usuario y responde únicamente si detecta una pregunta coherente (que finalice con el signo **"?"**).
* **Respuestas Dinámicas:** Aaron responde con un **"Sí"** o un **"No"** de forma aleatoria ante tus dudas.

## Contexto del Proyecto

Este proyecto es parte de mi proceso de aprendizaje en el **Curso de Flutter**. El objetivo principal fue poner en práctica:
1. Estructuración de un proyecto desde cero.
2. Uso de `ListView.builder` para renderizar mensajes dinámicamente.
3. Personalización de temas y colores (`ThemeData`).
4. Lógica básica de validación de texto en Dart.
